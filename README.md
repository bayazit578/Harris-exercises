# Упражнения из книги Дэвида Харриса и Сары Харрис "Цифровая схемотехника и архитектура компьютера"

## Сборка и запуск

Упражнения синтезировались и запускались в симуляторе [Icarus Verilog](https://github.com/steveicarus/iverilog)

Чтобы собрать проект и запустить симуляцию, перейдите в директорию с упражнением и выполните
```sh
make
make run
```

## Просмотр временных диаграмм

Для просмотра временных диаграмм использовалась программа [Surfer](https://app.surfer-project.org/). Однако вы можете использовать любой другой просмотрщик waveform-файлов, поддерживающий используемый формат.

Чтобы просмотреть результаты тестирования в виде waveform выполните
```sh
make wave
```
